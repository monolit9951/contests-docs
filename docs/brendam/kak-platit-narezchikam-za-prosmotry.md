# Как платить нарезчикам за просмотры

Чтобы платить нарезчикам за просмотры автоматически, создайте конкурс с оплатой за просмотры на DareBay. Вы задаёте ставку за 1000 просмотров, порог и потолок, блокируете бюджет на платформе - и дальше всё происходит без вашего участия. Оракул считает просмотры через API площадки, система распределяет бюджет по формуле, каждый нарезчик получает свою долю на кошелёк, карту или другим способом. Платформа работает как посредник-гарант: деньги заморожены до финализации, выплата автоматическая по независимому подсчёту. Остаток бюджета возвращается вам.

## Как устроена модель оплаты

1. **Вы создаёте конкурс и блокируете бюджет.** Откройте [создание конкурса на DareBay](https://darebay.com), выберите тип оплаты за просмотры, укажите задание для нарезчиков и внесите бюджет. Сумма замораживается и привязывается к конкурсу - забрать её до завершения нельзя. Это гарантия для нарезчиков: деньги уже на платформе, организатор не может передумать.
2. **Нарезчики публикуют работы и присылают ссылки.** Авторы видят ваш конкурс, берут задание, снимают контент и публикуют ролики с нужным хештегом. Затем каждый присылает на DareBay ссылку на свой ролик - работа попадает в конкурс только после этого.
3. **Оракул валидирует просмотры.** Платформа автоматически подтягивает данные о просмотрах через API площадки (сегодня это TikTok). Работы с признаками накрутки уходят на проверку и могут быть отклонены целиком. Подробнее о том, как считаются просмотры, читайте на [отдельной странице](/zarabotok/kak-schitayutsya-prosmotry-dlya-vyplaty).
4. **Система раздаёт бюджет по формуле.** Каждый нарезчик получает свою долю автоматически - на кошелёк, карту, банковский перевод, Telegram Stars или подарки. Неизрасходованный остаток возвращается на ваш баланс.

Пошаговая настройка конкурса (как выбрать ставку, порог и потолок под вашу задачу) - на странице [Как создать конкурс для нарезчиков](/brendam/kak-sozdat-konkurs-dlya-narezchikov).

## Ставка, порог, потолок и формула

Модель оплаты задают три параметра:

- **Ставка** - сколько вы платите за 1000 просмотров. Вы выбираете сумму при создании конкурса.
- **Порог** - минимальное количество просмотров, чтобы работа участвовала в распределении. Работы ниже порога не получают выплату.
- **Потолок** - максимальная сумма на одну работу. Защищает от того, чтобы один вирусный ролик забрал весь бюджет.

Когда конкурс завершается, система считает выплату для каждой работы:

> просмотры работы / 1000 * ставка

Работы ниже порога не участвуют. Потолок ограничивает максимум на одну работу.

## Комиссия

Отдельной платы за создание конкурса нет. Единственная комиссия считается как процент от суммы приза и платится один раз при создании конкурса - сверх бюджета. Призовой пул уходит нарезчикам целиком, из выплат ничего не удерживается.

| Параметр | Значение | Пояснение |
|----------|----------|-----------|
| Комиссия (карта, банковский перевод) | 5% от суммы приза | Платится сверх бюджета при создании конкурса |
| Комиссия (кошелёк, USDT на TON) | 8% от суммы приза | Платится сверх бюджета при создании конкурса |
| Комиссия (COINS) | 10% от суммы приза | Платится сверх бюджета при создании конкурса |
| Возврат остатка | автоматически | Неизрасходованная часть бюджета возвращается на баланс организатора |

Цифры на этой странице - из данных платформы DareBay (snapshot: 2026-07-10).

## Почему это работает для заказчика

**Бюджет защищён.** Вы платите только за реальные просмотры. Если нарезчики не набрали просмотров, бюджет вернётся.

**Не нужно договариваться с каждым.** Вы создаёте один конкурс, нарезчики сами берут задание. Платформа сама считает, сама платит.

**Независимый подсчёт.** Просмотры считает оракул через API площадки. Ни вы, ни нарезчики не можете подкрутить цифры.

**Автоматическая раздача.** Выплата каждому нарезчику идёт по формуле без вашего участия. Не нужно вручную переводить деньги десяти авторам.

## Часто задаваемые вопросы

### Сколько стоит создать конкурс?

Отдельной платы за создание нет. При создании конкурса списывается комиссия от суммы приза: фиат (карта, банковский перевод) - **5%**, кошелёк (USDT на TON) - **8%**, COINS (внутренняя валюта платформы) - **10%**. Комиссия платится сверх бюджета, призовой пул не уменьшается. Подробнее о комиссии - в [разделе FAQ](/pomoshch/kakaya-komissiya).

### Что если нарезчики не наберут просмотры?

Если работы не набрали минимальный порог просмотров или участников не было вообще, весь бюджет возвращается на ваш баланс автоматически. Заблокированный бюджет не пропадает.

### Как вернётся остаток?

Остаток возвращается на баланс организатора автоматически после завершения конкурса и распределения выплат. Если бюджет $200, а выплачено $70, оставшиеся $130 вернутся на ваш баланс.

### Можно ли менять ставку после создания конкурса?

Ставка и порог фиксируются при создании конкурса и не меняются. Это часть гарантии: нарезчики видят условия заранее, и организатор не может поменять их задним числом. Потолок выплаты на одну работу заказчик может скорректировать позже.

### Как нарезчики получают деньги?

Нарезчики получают выплату автоматически после завершения конкурса. Доступные способы: кошелёк (USDT на TON), банковская карта, банковский перевод, Telegram Stars, Telegram-подарки.

### Нужно ли мне самому проверять просмотры?

Нет. Просмотры считает оракул - автоматическая система, которая забирает данные из API площадки. Вам не нужно ничего проверять или подтверждать вручную. Платформа всё делает сама.
