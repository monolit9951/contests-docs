# For brands

You fund the budget up front, set a rate per 1000 views and a cap per submission. Clippers film,
publish and send in their links, and the platform pays each of them for the views they actually
got, counted independently of you and of them. In a wallet-backed contest, whatever the clippers
did not earn returns to your balance.

Everything the paying side needs is here: how pay-per-view works from the buyer's seat, how to set
up a contest for clippers, and how to commission clips for a campaign. The view figure is read
from the published view counter on the site each video went out on - not supplied by the creator
who submitted it, and not adjustable by either of you.

Contests run on TikTok, YouTube and Instagram; each contest names the site it wants.

Ready to run one - the [business page](/en/for-business) covers pricing and terms, and the
contest itself is set up on [darebay.com](https://darebay.com).
