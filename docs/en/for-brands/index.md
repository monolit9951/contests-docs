# For brands

Everything the paying side needs: how pay-per-view works from the buyer's seat, how to set up
a contest for clippers, and how to commission clips for a campaign.

The model is simple. You fund the budget up front, set a rate per thousand views and a cap
per submission; creators film and publish; the platform pays out against independently
counted views. Views short of the budget are refunded. Inflated views cannot be paid for:
an oracle counts them, not the creator who submitted the work.

Ready to run one — the [business page](/en/for-business) covers pricing and terms, and the
contest itself is set up on [darebay.com](https://darebay.com).
