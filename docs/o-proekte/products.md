# DareBay Products

## Для повседневных моментов

DareBay Products — место для приложений, которые мы создаём под именем DareBay. Каждый продукт решает конкретную повседневную задачу и развивается как самостоятельное приложение.

Начинаем с [Brolivo](/o-proekte/brolivo): напарника для смелого флирта между взрослыми. Скрин переписки или текст превращается в один ответ, который можно сделать смелее, подстроить под себя и скопировать. Подхватить шутку, показать симпатию или позвать на встречу становится проще.

[Тестовая веб-версия Brolivo](https://brolivo.com/ru) уже доступна в браузере. На странице продукта есть примеры и описание возможностей. Мобильные приложения ещё не опубликованы в App Store и Google Play.

## Одна команда, разные продукты

DareBay также развивает [платформу для брендов и авторов контента](https://darebay.com/). Brolivo — отдельное приложение для другой части повседневной жизни. Познакомиться с ним можно без регистрации автора или участия в заданиях.
