# DareBay реально платит - как выплата обеспечена

Да, DareBay реально платит. Площадка работает как посредник-гарант: бюджет конкурса замораживается при создании, результаты считает система через API площадок, а выплата идёт автоматически по валидированным просмотрам или другим результатам. Организатор не может забрать деньги обратно после публикации конкурса. Участник не платит ни за участие, ни за вывод. Ниже разберём, как именно это устроено и какими способами приходит награда.

## Как обеспечена выплата

Механика посредника-гаранта работает в три шага:

1. **Организатор замораживает бюджет при создании конкурса.** Деньги списываются с баланса организатора и хранятся на платформе. После публикации организатор не может их вернуть или перенаправить.
2. **Система считает результаты.** Просмотры подтягиваются автоматически через API площадок (TikTok, YouTube). Голоса и выбор победителя тоже проходят через платформу. Ни организатор, ни участник не могут подкрутить цифры.
3. **Выплата идёт автоматически.** Когда конкурс завершается, платформа сама распределяет приз по валидированным результатам. Организатор не нажимает кнопку «заплатить», процесс происходит без его участия.

Участник не рискует деньгами: нет депозита, нет платы за участие, нет комиссии за вывод.

## Почему деньги не могут пропасть

Приз не хранится на счёте организатора. После создания конкурса деньги находятся на платформе и привязаны к конкретному конкурсу. Ни организатор, ни платформа не могут потратить эти средства на что-то другое.

Выплата происходит по одному из сценариев:

- **Pay-per-view конкурсы.** Система подсчитывает просмотры каждой работы через API площадок и распределяет бюджет пропорционально валидированным просмотрам.
- **Конкурсы с голосованием или выбором жюри.** Приз уходит победителю после финализации результатов.
- **Случайный выбор.** Система делает честный рандомный выбор среди участников.

Если конкурс завершается без участников или с неиспользованным остатком, средства возвращаются организатору.

## Способы получения награды

На DareBay крипта - один вариант из нескольких. Доступные способы получить награду:

- **Кошелёк** (крипта, USDT на TON)
- **Карта** (банковская карта)
- **Банковский перевод**
- **Вещь** (предметный приз от организатора)
- **Telegram Stars**
- **Telegram-подарки**

Фиат (карта, банковский перевод) работает наравне с кошельком. Выбор способа зависит от конкретного конкурса и предпочтений участника.
