# DareBay вывод денег - как вывести, сроки, бесплатно

Вывод денег с DareBay бесплатный. Платформа не берёт комиссию за вывод - ни скрытую, ни открытую. Мы никогда не берём деньги за вывод. Комиссию платит только организатор при создании конкурса, а победитель получает полную сумму приза. Вывести можно на кошелёк (крипта), карту, банковский перевод. Также доступны Telegram Stars и подарки. Ниже разберём шаги вывода, сроки и пороги для pay-per-view конкурсов.

## Шаги вывода

Вывод занимает три шага:

1. **Конкурс завершается, результаты подтверждаются.** После окончания конкурса система проходит этап подтверждения. Минимальное окно подтверждения - 2 дня (48 часов, 2880 минут). За это время платформа валидирует результаты через API площадок.
2. **Приз зачисляется на баланс.** После подтверждения приз автоматически появляется в кошельке в статусе "доступный". Организатор не участвует в этом процессе - деньги были заморожены на платформе с момента создания конкурса.
3. **Вывод на выбранный способ.** Из доступного баланса можно вывести на кошелёк, карту или банковский счёт. Сроки зависят от способа: кошелёк - минуты, карта - обычно в тот же день, банковский перевод - 1-3 рабочих дня.

DareBay работает как посредник-гарант: деньги заморожены до старта, выплата автоматическая, участник не платит ни за участие, ни за вывод.

## Порог просмотров для pay-per-view

В pay-per-view конкурсах есть порог минимальных просмотров для выплаты. Текущий живой порог - **2000 просмотров**. Если работа не набрала этот минимум, выплата по ней не начисляется.

Это защита от накруток и пустых работ: платформа платит только за реальный охват, подтверждённый через API площадок. Просмотры считает система автоматически, ни организатор, ни участник не могут подкрутить цифры.

Порог устанавливает организатор при создании конкурса. Значение 2000 просмотров - это живая медиана по активным конкурсам на платформе.

## Контраст со скам-схемами

Типичная скам-площадка просит деньги за вывод: "заплатите комиссию, чтобы получить выигрыш". Это классический признак мошенничества. На DareBay всё наоборот:

- **Мы никогда не берём деньги за вывод.** Ни при каком сценарии.
- **Комиссию платит организатор**, а не участник. И платит при создании конкурса, не при выводе.
- **Приз заморожен заранее.** Деньги лежат на платформе с момента публикации конкурса. Они не могут исчезнуть.
- **Выплата автоматическая.** Система сама распределяет приз по результатам. Организатор не нажимает кнопку "заплатить".

Если площадка просит деньги за вывод - это не DareBay.

## Частые вопросы

### DareBay берёт деньги за вывод?

Нет. DareBay не берёт денег за вывод. Комиссию платит организатор при создании конкурса, а победитель получает полную сумму приза. Мы никогда не берём деньги за вывод. Подробнее о комиссиях: [какая комиссия на DareBay](./fees).

### Сколько ждать вывода на DareBay?

После завершения конкурса система проходит этап подтверждения результатов - минимум 2 дня (48 часов). После этого приз автоматически зачисляется на баланс. Вывод на кошелёк занимает минуты, на карту - обычно в тот же день, банковский перевод - 1-3 рабочих дня.

### Есть ли минимальная сумма для вывода?

Минимальная сумма зависит от способа вывода. Для кошелька ограничение определяется комиссией сети (gas), для карты и банковского перевода - условиями провайдера. Точные лимиты показаны в настройках кошелька.

### Куда можно вывести деньги с DareBay?

Кошелёк (крипта, USDT на TON), банковская карта, банковский перевод. Также доступны Telegram Stars и Telegram-подарки. Крипта - один вариант из нескольких, фиат работает наравне. Подробнее: [как вывести выигрыш](./withdraw).

### Какой порог просмотров для выплаты в pay-per-view?

Текущий живой порог - 2000 просмотров. Если работа не набрала этот минимум, выплата по ней не начисляется. Просмотры считает система автоматически через API площадок.

### Почему деньги не приходят сразу после конкурса?

После завершения конкурса система проходит этап подтверждения результатов. Окно подтверждения составляет минимум 2 дня (48 часов). После этого приз автоматически зачисляется на баланс. Это нужно для валидации результатов и защиты от накруток.

### Что делать, если вывод не приходит?

Проверьте статус баланса в кошельке: если средства в статусе "замороженный", конкурс ещё не завершён или идёт этап подтверждения. Если баланс "доступный", но вывод не дошёл - напишите на support@darebay.com. Подробнее о статусах баланса: [как вывести выигрыш](./withdraw).
