# Отправить работу

Отправить работу на DareBay быстрее, чем прочитать инструкцию про это.

## 1. Найди подходящий конкурс

Листай ленту или фильтруй по категории. Открой карточку конкурса.
**Внимательно прочитай условия** — большинство дисквалификаций случается
потому, что кто-то проскочил по диагонали и упустил требование.

Проверь:

- Он ещё **ACTIVE**? (В закрытые конкурсы работы не принимаются.)
- Какой формат нужен? (Текст / изображение / видео — обычно только один.)
- Жёсткие ограничения: язык, оригинальность, длина.

## 2. Сделай работу

Реально сделай. Украденный контент, AI-слоп под видом авторского, другие
обходные пути — всё это удаляется, а аккаунты получают отметки. Твой
**рейтинг участника** следует за тобой по всей платформе — он стоит больше
любого отдельного приза.

## 3. Загрузи работу

На странице конкурса нажми **Отправить**. В зависимости от формата:

- **Текст** — набери или вставь.
- **Изображение** — загрузка (jpg, png, webp).
- **Видео** — загрузка; видео попадает в хранилище DareBay и кодируется
  под стриминг. Держись в рамках лимита размера, указанного в форме.

Можно добавить короткую заметку, поясняющую работу — полезно для конкурсов
с отбором организатором.

## 4. Жди этап выбора

После дедлайна приёма конкурс переходит в **SELECTION_IN_PROGRESS**. Что
дальше — зависит от типа отбора:

- **Голосование сообщества** — голосуют зрители; можешь делиться работой,
  чтобы собрать поддержку.
- **Выбор автором** — организатор смотрит и решает.
- **Случайный среди топа** — выбирает система.

## 5. Если выиграл

Придёт уведомление. Для **MONEY**-призов средства уже заморожены в конкурсе —
они переходят на твой баланс, как только организатор подтверждает (или
автоматически, в зависимости от типа). Для **ITEM**-призов организатор
связывается с тобой, чтобы договориться о передаче.

## 6. Если не выиграл

Нормально. Заходи в следующий. Рейтинг участника подрастает уже за то, что
ты присылаешь настоящие работы и не нарушаешь правил — репутацию зарабатывают
не только победители.
