# Как платить нарезчикам за просмотры

Чтобы платить нарезчикам за просмотры автоматически, создайте PPV-конкурс на DareBay. Вы задаёте ставку за 1000 просмотров, порог и потолок, блокируете бюджет на платформе - и дальше всё происходит без вашего участия. Оракул считает просмотры через API площадок, система распределяет бюджет по формуле, каждый нарезчик получает свою долю на кошелёк, карту или другим способом. Платформа работает как посредник-гарант: деньги заморожены до финализации, выплата автоматическая по независимому подсчёту. Остаток бюджета возвращается вам.

## Пошаговая цепочка для заказчика

### 1. Создать PPV-конкурс

Откройте создание конкурса и выберите тип оплаты за просмотры. Стоимость создания конкурса - **10 USDT**. Укажите задание для нарезчиков: какой контент нужен, на какой площадке публиковать, какой хештег использовать.

### 2. Задать ставку, порог и потолок

Три ключевых параметра:

- **Ставка** - сколько вы платите за 1000 просмотров. Вы выбираете сумму при создании конкурса.
- **Порог** - минимальное количество просмотров, чтобы работа участвовала в распределении. Работы ниже порога не получают выплату.
- **Потолок** - максимальная сумма на одну работу. Защищает от того, чтобы один вирусный ролик забрал весь бюджет.

### 3. Заблокировать бюджет

Внесите бюджет конкурса на платформу. Сумма замораживается и привязывается к конкретному конкурсу. Забрать её обратно до завершения нельзя. Это гарантия для нарезчиков: деньги уже на платформе, организатор не может передумать.

### 4. Нарезчики публикуют работы

Авторы видят ваш конкурс, берут задание, снимают контент и публикуют на площадке с нужным хештегом. Каждая работа регистрируется в системе.

### 5. Оракул валидирует просмотры

Платформа автоматически подтягивает данные о просмотрах через API площадок (TikTok, YouTube). Просмотры проходят валидацию: накрутка отсекается. Подробнее о том, как считаются просмотры, читайте на [отдельной странице](./kak-schitayutsya-prosmotry-dlya-vyplaty).

### 6. Автоматическая раздача по формуле

Когда конкурс завершается, система считает выплату для каждой работы:

> просмотры работы / 1000 * ставка

Работы ниже порога не участвуют. Потолок ограничивает максимум на одну работу. Каждый нарезчик получает свою долю автоматически - на кошелёк, карту, банковский перевод, Telegram Stars или подарки.

Неизрасходованный остаток бюджета возвращается на ваш баланс.

## Стоимость и комиссия

| Параметр | Значение | Пояснение |
|----------|----------|-----------|
| Создание конкурса | 10 USDT | Фиксированная стоимость создания PPV-конкурса |
| Комиссия (карта, банк) | 5% | Удерживается при создании конкурса с бюджетом в фиате |
| Комиссия (кошелёк) | 8% | Удерживается при создании конкурса с бюджетом в крипте |
| Комиссия (COINS) | 10% | Удерживается при создании конкурса с бюджетом в COINS |
| Возврат остатка | автоматически | Неизрасходованная часть бюджета возвращается на баланс организатора |

Комиссия списывается один раз при создании конкурса. Нарезчики получают выплату без дополнительных удержаний со своей стороны.

## Почему это работает для заказчика

**Бюджет защищён.** Вы платите только за реальные просмотры. Если нарезчики не набрали просмотров, бюджет вернётся.

**Не нужно договариваться с каждым.** Вы создаёте один конкурс, нарезчики сами берут задание. Платформа сама считает, сама платит.

**Независимый подсчёт.** Просмотры считает оракул через API площадок. Ни вы, ни нарезчики не можете подкрутить цифры.

**Автоматическая раздача.** Выплата каждому нарезчику идёт по формуле без вашего участия. Не нужно вручную переводить деньги десяти авторам.

## Часто задаваемые вопросы

### Сколько стоит создать конкурс?

Создание PPV-конкурса стоит **10 USDT**. Это фиксированная стоимость, которая не зависит от размера бюджета.

### Какая комиссия?

Комиссия зависит от способа оплаты бюджета. Фиат (карта, банковский перевод) - **5%**. Кошелёк (крипта) - **8%**. COINS (внутренняя валюта платформы) - **10%**. Комиссия удерживается один раз при создании конкурса. Подробнее о комиссиях - в [разделе FAQ](../faq/kakaya-komissiya).

### Что если нарезчики не наберут просмотры?

Если работы не набрали минимальный порог просмотров или участников не было вообще, весь бюджет возвращается на ваш баланс автоматически. Деньги не пропадают.

### Как вернётся остаток?

Остаток возвращается на баланс организатора автоматически после завершения конкурса и распределения выплат. Если бюджет $200, а выплачено $70, оставшиеся $130 вернутся на ваш баланс.

### Можно ли менять ставку после создания конкурса?

Нет. Параметры конкурса (ставка, порог, потолок, бюджет) фиксируются при создании. Это часть гарантии: нарезчики видят условия заранее, и организатор не может их поменять задним числом.

### Как нарезчики получают деньги?

Нарезчики получают выплату автоматически после завершения конкурса. Доступные способы: кошелёк (USDT на TON), банковская карта, банковский перевод, Telegram Stars, Telegram-подарки.

### Нужно ли мне самому проверять просмотры?

Нет. Просмотры считает оракул - автоматическая система, которая забирает данные из API площадок. Вам не нужно ничего проверять или подтверждать вручную. Платформа всё делает сама.
