# Заработок на DareBay

Здесь — разборы того, сколько и как зарабатывают авторы на DareBay: оплата за просмотры,
заработок в конкурсах, кейсы для нарезчиков. Цифры берём из реальных данных платформы.

Платформа держит приз заранее и выплачивает его автоматически по независимо посчитанным
результатам, чтобы никого не кинули. Подробнее о механике — в разделе
[Как это работает](/ru/kak-rabotaet/).
