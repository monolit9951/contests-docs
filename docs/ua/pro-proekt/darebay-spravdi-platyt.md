# DareBay справді платить - як забезпечена виплата

Так, DareBay справді платить. Майданчик працює як посередник-гарант: бюджет конкурсу заморожується при створенні, результати рахує система через API майданчиків, а виплата йде автоматично за валідованими переглядами чи іншими результатами. Організатор не може забрати гроші назад після публікації конкурсу. Учасник не платить ні за участь, ні за виведення. Нижче розберемо, як саме це влаштовано і якими способами приходить нагорода.

## Як забезпечена виплата

Механіка посередника-гаранта працює в три кроки:

1. **Організатор заморожує бюджет при створенні конкурсу.** Гроші списуються з балансу організатора і зберігаються на платформі. Після публікації організатор не може їх повернути або перенаправити.
2. **Система рахує результати.** Перегляди підтягуються автоматично через API майданчиків (сьогодні TikTok). Голоси і вибір переможця теж проходять через платформу. Ні організатор, ні учасник не можуть підкрутити цифри.
3. **Виплата йде автоматично.** Коли конкурс завершується, платформа сама розподіляє приз за валідованими результатами. Організатор не натискає кнопку «заплатити», процес відбувається без його участі.

Учасник не ризикує грошима: немає депозиту, немає плати за участь, немає комісії за виведення.

## Чому гроші не можуть зникнути

Приз не зберігається на рахунку організатора. Після створення конкурсу гроші перебувають на платформі і прив'язані до конкретного конкурсу. Ні організатор, ні платформа не витрачають ці кошти ні на що інше: бюджет закріплений за конкурсом до його завершення і йде тільки на виплати за ним.

Виплата відбувається за одним зі сценаріїв:

- **Pay-per-view конкурси.** Система підраховує перегляди кожної роботи через API майданчиків і розподіляє бюджет пропорційно валідованим переглядам.
- **Конкурси з голосуванням або вибором журі.** Приз іде переможцю після фіналізації результатів.
- **Випадковий вибір.** Система робить чесний рандомний вибір серед учасників.

Якщо конкурс завершується без учасників або з невикористаним залишком, кошти повертаються організатору.

## Способи отримання нагороди

На DareBay гаманець - один спосіб із кількох. Доступні способи отримати нагороду:

- **Гаманець** (USDT на TON)
- **Картка** (банківська картка)
- **Банківський переказ**
- **Річ** (предметний приз від організатора)
- **Telegram Stars**
- **Telegram-подарунки**

Фіат (картка, банківський переказ) працює нарівні з гаманцем. Вибір способу залежить від конкретного конкурсу і вподобань учасника.
