# DareBay Products

## Для щоденних моментів

DareBay Products — місце для застосунків, які ми створюємо під ім’ям DareBay. Кожен продукт розв’язує конкретну щоденну задачу й розвивається як самостійний застосунок.

Починаємо з Brolivo — помічника у спілкуванні для дорослих, які знайомляться та пізнають одне одного. На сторінці продукту розповідаємо, для чого він потрібен, чим може допомогти та на якому етапі зараз запуск.

## Одна команда, різні продукти

DareBay також розвиває [платформу для брендів і авторів контенту](https://darebay.com/). Brolivo — окремий застосунок для іншої частини щоденного життя. Ознайомитися з ним можна без реєстрації автора чи участі в завданнях.

Якщо маєте запитання про продукт або ідею співпраці, напишіть нам за адресою нижче. Нові застосунки додаватимемо сюди в міру їх появи.
