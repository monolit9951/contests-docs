# Заробіток на DareBay

Тут - розбори того, скільки і як заробляють автори на DareBay: оплата за перегляди,
заробіток у конкурсах, кейси для нарізальників. Цифри беремо з реальних даних платформи.

Платформа тримає приз наперед і виплачує його автоматично за незалежно підрахованими
результатами, щоб нікого не ошукали. Докладніше про механіку - у розділі
[Як це працює](/ua/yak-tse-pratsiuie).
