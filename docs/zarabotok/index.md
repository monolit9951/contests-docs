# Заработок на DareBay

Здесь разобрано, сколько зарабатывают авторы на DareBay и на чём: оплата за просмотры,
заработок в конкурсах, расчёты для нарезчиков. Все цифры взяты из данных платформы, а не
из чужих оценок.

Приз лежит на платформе ещё до того, как вы взяли задание, и расходится авторам по независимо
посчитанным результатам. Заказчик не может передумать: деньги защищены. Механика целиком в
разделе [Как это работает](/how-it-works).
