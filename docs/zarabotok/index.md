# Заработок на DareBay

Здесь разобрано, сколько зарабатывают авторы на DareBay и на чём: оплата за просмотры,
заработок в конкурсах, расчёты для нарезчиков. Все цифры взяты из данных платформы, а не
из чужих оценок.

Бюджет фиксируется за конкурсом ещё до того, как вы взяли задание. По независимо
посчитанным результатам платформа сохраняет начисления или обязательства; исполнение может быть
ручным. Механика целиком в разделе [Заработок на нарезках](/earn/clips).
