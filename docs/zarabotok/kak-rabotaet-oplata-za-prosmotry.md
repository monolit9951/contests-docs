# Как работает оплата за просмотры на DareBay

Оплата за просмотры (PPV-конкурс) на DareBay работает так: организатор блокирует бюджет на платформе, нарезчики публикуют свой контент, платформа автоматически считает просмотры через API площадок и распределяет деньги по формуле. Каждый автор получает долю пропорционально реальным просмотрам. Платформа выступает посредником-гарантом: деньги заморожены до финализации, организатор не может их забрать, а выплата идёт автоматически без участия человека. Нарезчику не нужно договариваться с заказчиком напрямую.

Все цифры на этой странице взяты из данных платформы (snapshot: 2026-07-11).

## Полная цепочка: от бюджета до выплаты

Вот что происходит от момента создания конкурса до получения денег:

1. **Организатор блокирует бюджет.** При создании PPV-конкурса организатор задаёт параметры (ставка, порог, потолок) и замораживает весь бюджет на платформе. Деньги списываются с баланса организатора и привязаны к конкретному конкурсу. Забрать их обратно до завершения нельзя.

2. **Нарезчики публикуют работы и присылают ссылки.** Авторы берут задание, снимают контент и публикуют на TikTok с нужным хештегом (площадка указана в задании). Затем каждый присылает на DareBay ссылку на свой ролик - работа попадает в конкурс только после этого.

3. **Оракул считает просмотры.** Платформа автоматически подтягивает данные о просмотрах через API площадок. Просмотры проходят валидацию: система проверяет их на предмет накрутки. Подробнее: [как считаются просмотры для выплаты](/zarabotok/kak-schitayutsya-prosmotry-dlya-vyplaty).

4. **Детерминированный сплит по формуле.** Когда конкурс завершается, система считает выплату для каждой работы: `просмотры / 1000 * ставка`. Работы, не набравшие минимальный порог просмотров, не участвуют в распределении. Потолок на одну работу ограничивает максимальную сумму.

5. **Автоматическая выплата.** Каждый нарезчик получает свою долю на кошелёк, карту или другим выбранным способом. Выплата идёт без участия организатора.

6. **Остаток возвращается организатору.** Если бюджет израсходован не полностью (мало участников, работы не набрали просмотров), неизрасходованная часть автоматически возвращается на баланс организатора.

## Параметры PPV-механики

| Параметр | Значение | Что означает |
|----------|----------|--------------|
| Медианная ставка | $0.50 за 1000 просмотров | Типичная ставка оплаты в живых конкурсах |
| Порог просмотров | 2000 просмотров | Типичное значение в живых конкурсах; точный порог задаёт организатор |
| Потолок на одну работу | $50 | Типичное значение в живых конкурсах; максимум на одну работу |
| Окно отбора | 24 часа | Время, за которое организатор проверяет работы после завершения приёма |
| Окно подтверждения | 48 часов (2 дня) | Время на подтверждение результатов перед выплатой |

Организатор задаёт ставку, порог и потолок при создании конкурса. Порог просмотров защищает бюджет от размазывания на десятки работ с единичными просмотрами.

## Как считается выплата: пример

Допустим, организатор создаёт конкурс с бюджетом $200, ставкой $0.50 за 1000 просмотров, порогом 2000 просмотров и потолком $50 на работу. Три нарезчика пришлют работы:

- **Автор А:** если его ролик наберёт 120 000 просмотров, расчёт: 120 000 / 1000 * $0.50 = $60. Но потолок $50, поэтому автор получит **$50**.
- **Автор Б:** если ролик наберёт 40 000 просмотров, расчёт: 40 000 / 1000 * $0.50 = $20. Потолок не достигнут, автор получит **$20**.
- **Автор В:** если ролик наберёт 1500 просмотров, порог 2000 не будет достигнут, и работа **не участвует** в распределении.

Итого будет выплачено: $50 + $20 = $70. Оставшиеся $130 вернутся организатору.

Потолок действует на одну работу: можно прислать несколько разных роликов, каждый считается отдельно.

## Зачем нужен порог и потолок

**Порог** (2000 просмотров) отсекает работы с минимальным охватом. Без порога бюджет размазывался бы на сотни работ, которые набрали по 10-50 просмотров. Порог мотивирует авторов делать качественный контент, который реально смотрят.

**Потолок** ($50 на работу) не даёт одному автору забрать весь бюджет. Если один ролик завирусился на миллион просмотров, без потолка он бы съел весь пул. С потолком остаток сверх лимита возвращается организатору.

## Часто задаваемые вопросы

### Кто считает просмотры?

Платформа подтягивает просмотры автоматически через API площадки (сегодня это TikTok). Ни организатор, ни участник не вводят цифры вручную. Это независимый подсчёт, который ни одна сторона не может подкрутить.

### Что если кто-то накрутил просмотры?

Система валидирует просмотры перед распределением. Подозрительные всплески (боты, накрутка) проверяются и могут быть отклонены. Детали: [как считаются просмотры для выплаты](/zarabotok/kak-schitayutsya-prosmotry-dlya-vyplaty).

### Когда придут деньги?

После завершения конкурса идёт окно отбора (до 24 часов) и окно подтверждения (до 48 часов). После этого выплата идёт автоматически. Итого от завершения приёма работ до денег обычно не больше 3 дней.

### Какими способами можно получить выплату?

DareBay поддерживает несколько способов: кошелёк (USDT на TON), банковская карта, банковский перевод, Telegram Stars, Telegram-подарки. Кошелёк - один способ из нескольких.

### Что если конкурс не набрал участников?

Если ни одна работа не набрала порог просмотров (или работ не было вообще), весь бюджет возвращается организатору. Деньги не пропадают.

### Организатор может не заплатить?

Нет. Бюджет замораживается при создании конкурса. Организатор не участвует в процессе выплаты. Платформа работает как посредник-гарант: деньги заблокированы, выплата автоматическая.

### Есть ли минимальная сумма для участия?

Для нарезчика минимума нет: участие бесплатно, депозитов нет. Единственное условие - набрать порог просмотров, указанный в конкурсе (типично 2000), чтобы работа участвовала в распределении.
